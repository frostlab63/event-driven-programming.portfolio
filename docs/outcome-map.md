# Outcome map

The repository is organized around evidence rather than copied tutorial prose.

| Course outcome | Evidence | Verification |
|---|---|---|
| Identify event source, event, listener, handler | Week 1 event map and calculator | Readable mapping plus runnable calculator |
| Implement loose notification | Week 2 observer interfaces | Demo output and unit-style assertions |
| Protect Swing's EDT | Weeks 3–5 applications | `SwingUtilities.invokeLater` in entry points |
| Handle user interaction | Week 4 form | Action, item, and document listeners |
| Build data-heavy desktop UI | Week 5 explorer | JTable/JTree/JList and custom renderer |
| Separate JavaFX view and logic | Week 6 FXML module | FXML controller boundary |
| Control event propagation | Week 7 | Filter consumes blocked key event |
| Build reactive models | Week 8 | Bidirectional and derived bindings |
| Keep UI responsive | Week 9 | Background Task with progress/cancel |
| Integrate architecture | Week 10 | MySQL schema, DAO boundary, Task, scheduler |

## Verification principle

A claim is included only when it points to code, SQL, or a repeatable command. GUI evidence is secondary in this portfolio; the source and its explanation carry the main argument.
