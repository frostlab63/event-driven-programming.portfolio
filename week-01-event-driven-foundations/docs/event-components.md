# Activity 1 — Event components

| System | Event source | Event | Listener | Handler/action |
|---|---|---|---|---|
| ATM | Keypad | PIN key pressed | Transaction controller | Append digit and validate |
| ATM | Card slot | Card inserted | Card reader service | Read account token |
| Microwave | Keypad | Time button pressed | Cooking controller | Update countdown |
| Traffic lights | Timer | Phase timer expires | Signal controller | Change light phase |
| Video game | Keyboard | Movement key pressed | Input manager | Update player position |
| Elevator | Floor button | Floor selected | Elevator controller | Queue destination |
| Smartphone | Touchscreen | Swipe detected | Gesture recognizer | Change view |
| Online shop | Add-to-cart button | Click | Cart listener | Add item and update total |
| Smart home | Door sensor | Door opened | Security controller | Log or raise alarm |

The table is more useful than a definition copied from a textbook because it forces each concept to be attached to a concrete source and response.
