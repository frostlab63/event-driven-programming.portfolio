# Week 1 — Event-driven foundations

This week makes the vocabulary concrete. `EventDrivenCalculator` separates a source (button), event (click), listener, and handler. `EventMap` records the same relationship in a form that can be checked before code is written.

## Learning outcomes

- Define event, source, listener, and handler.
- Compare procedural and event-driven control flow.
- Explain the event queue and EDT.
- Identify event-driven systems in daily software.

## Run

```bash
javac src/*.java
java -cp src EventDrivenCalculator
```
